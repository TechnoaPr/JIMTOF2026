# JIMTOF2026 ブース巡回（非公式）公開・運用手順書

Xの公式アカウントがある出展社を巡回するための、スマホ向けWebアプリです。
GitHub Pages（無料）で公開し、出展社データはGoogleスプレッドシート（無料）で追加・編集します。

## 同梱ファイル

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体（設定はファイル内の `CONFIG` だけ）。検索・絞り込み、公式マップ連携付き |
| data.csv | 出展社データ（28件・27社）。スプレッドシートの元データ兼、予備データ |
| sw.js | 会場で電波が弱くても開けるようにする仕組み |
| manifest.webmanifest / icons/ | 「ホーム画面に追加」したときの名前とアイコン |
| ogp.png | Xでリンクを投稿したときに表示されるカード画像 |

---

## 手順1　スプレッドシートを作る（約5分）

1. Googleドライブで新しいスプレッドシートを作ります。名前は「JIMTOF2026 出展社データ」など。
2. メニューの［ファイル］→［インポート］→［アップロード］で `data.csv` を選びます。
3. 「インポート場所」は［現在のシートを置換する］を選び、［データをインポート］を押します。
4. 画面下のシート名を `booths` に変更します。

社内メモやDMの記録を残したい場合は、**別のシート（タブ）**を作ってそちらに書いてください。次の手順で公開するのは `booths` シートだけです。

## 手順2　スプレッドシートをウェブに公開する（約2分）

1. ［ファイル］→［共有］→［ウェブに公開］を開きます。
2. 左側で `booths` シートを、右側で［カンマ区切り形式（.csv）］を選びます。
3. ［公開］を押し、表示されたURLをコピーします。
   - URLは `https://docs.google.com/spreadsheets/d/e/……/pub?gid=……&single=true&output=csv` の形です。

> このURLを知っている人は誰でも `booths` シートの内容を見られます。掲載内容はもともと公開情報なので問題ありませんが、非公開にしたい情報は `booths` に書かないでください。

## 手順3　アプリにURLを設定する（約2分）

`index.html` をテキストエディタ（メモ帳でも可）で開き、上のほうにある次の行にURLを貼ります。

```js
SHEET_CSV_URL: "ここに手順2でコピーしたURLを貼る",
```

## 手順4　GitHub Pagesで公開する（約10分）

1. GitHubにログインし、右上の［＋］→［New repository］を選びます。
2. Repository name に `jimtof2026-x` などと入力し、**Public** を選んで［Create repository］を押します。
3. 作成後の画面にある「uploading an existing file」をクリックし、同梱ファイルをすべてドラッグ＆ドロップします（`icons` フォルダごと入れてください）。
4. 下の［Commit changes］を押します。
5. リポジトリの［Settings］→ 左メニューの［Pages］を開き、
   - Source：［Deploy from a branch］
   - Branch：［main］／［/(root)］
   を選んで［Save］を押します。
6. 1〜2分後、同じ画面の上部に公開URL（`https://ユーザー名.github.io/jimtof2026-x/`）が表示されます。

## 手順5　Xのリンクカードを設定する（約3分）

`index.html` の中にある `https://YOUR-NAME.github.io/jimtof2026-x/` という部分（2か所）を、手順4で表示された実際のURLに書き換え、GitHubに再度アップロードします（同じ名前のファイルを上書きでアップロードすれば更新されます）。

## 手順6　公開前の確認

- iPhoneとAndroidの両方で開き、一覧・検索・絞り込み・詳細画面・Xボタンが動くか
- スプレッドシートの1行を試しに書き換え、数分後にアプリへ反映されるか
- Xにリンクを貼ったとき、カード画像が表示されるか（下書き画面で確認できます）

## 公開前に入れる素材（公式マップのURL）

`index.html` の上のほうにある `CONFIG` の中の `MAP_URLS` で、各エリアの `""` の中にJIMTOF公式サイトのエリアごとのマップのURLを貼ります。空欄のエリアは、JIMTOF公式サイトのトップページを開きます。

```js
e78: "https://www.jimtof.org/……", // 東7〜8ホール
```

あとから追加しても大丈夫です。

## iPhone・Androidでの確認ポイント

インストールは不要で、どちらもブラウザでそのまま使えます。公開前に、実機で次の点を確認してください。

- **iPhone（Safari）**：一覧・検索・絞り込み、詳細画面、Xボタン（Xアプリが入っていればアプリで開きます）、公式マップのリンク
- **Android（Chrome）**：上と同じ項目
- **両方**：機内モードにして再読み込みし、保存済みのデータで一覧が表示されるか

## 出展社データの追加・編集ルール

スプレッドシートの `booths` シートを編集するだけで、アプリに反映されます（Googleの仕様で、反映まで最大5分ほどかかります）。

| 列名 | 書き方 |
|---|---|
| id | 行ごとの番号。**一度使った番号は変えない・使い回さない**（詳細画面のURLになるため） |
| hall | 小間番号から自動で判定されるので、空欄で構いません。小間番号がない場合だけ参考に使います |
| booth_number | 例：`W1046`、`E3011-E3013`、`S1031-1`。わからなければ空欄（アプリには「調査中」と表示） |
| company_name | 企業名 |
| exhibit_features | 業務内容・展示の特徴 |
| x_account | `@` 付き・なし、プロフィールURLのどれでも可 |
| presence_status | `常駐予定` / `気まぐれ来店` / `情報募集中` のいずれか。それ以外の文字は「情報募集中」として扱います |
| evidence_url | 根拠になった投稿のURL、または「アカウントbio記載」などのメモ |

- **新しい出展社を追加するとき**：いちばん下の行に追記し、id は最後の番号の次にします。
- **1社で複数のブースがあるとき**：ブースごとに1行ずつ書きます（企業名は同じにする）。詳細画面に「この会社のほかのブース」として表示されます。
- **掲載をやめるとき**：行ごと削除します。

## ホールの自動判定

小間番号の先頭から、ホールを自動で判定します。

- `E1`〜`E3` → 東1〜3ホール、`E7`・`E8` → 東7〜8ホール
- `W1`・`W2` → 西1〜2ホール、`W3`・`W4` → 西3〜4ホール
- `S1`・`S2` → 南1〜2ホール、`S3`・`S4` → 南3〜4ホール

西アトリウムなど、この形に当てはまらない小間番号の場合は、`hall` 列に「西アトリウム」などと書けば、それをもとに絞り込みます。

## アクセス回数を計測する（Googleアナリティクス4・無料）

ブースごとの「見られた回数」と「Xボタンが押された回数」を計測できます。会期後に、各社へ反響をお伝えする材料になります。

### 設定（約10分）

1. [Googleアナリティクス](https://analytics.google.com/) にログインし、［管理］→［作成］→［プロパティ］で新しいプロパティを作ります（名前は「JIMTOF2026 ブース巡回」など）。
2. 「データストリーム」で［ウェブ］を選び、公開URLを入力して作成します。
3. 表示された測定ID（`G-` から始まる番号）を、`index.html` の `GA4_ID: ""` の `""` の中に貼ります。
4. ［管理］→［カスタム定義］→［カスタムディメンションを作成］で、次の2つを登録します（範囲はどちらも「イベント」）。
   - ディメンション名 `企業名` ／ イベントパラメータ `company`
   - ディメンション名 `小間番号` ／ イベントパラメータ `booth`
5. `index.html` をGitHubへ再アップロードします。

### 計測される内容

| イベント名 | 記録されるタイミング |
|---|---|
| page_view | アプリが開かれたとき（全体のアクセス数） |
| view_booth | ブースの詳細画面が開かれたとき |
| open_x | 詳細画面で「Xを開く」ボタンが押されたとき |

### 企業ごとの回数を見る方法

［探索］→［自由形式］を開き、ディメンションに「イベント名」と「企業名」、指標に「イベント数」を追加して表に並べます。
`view_booth` の行が詳細の閲覧数、`open_x` の行がXへの送客数です。カスタムディメンションは登録した時点から集計されるので、**公開前に手順4まで済ませておいてください**。


## アプリ本体を更新したとき

`index.html` を書き換えて再アップロードした場合は、`sw.js` の1行目付近にある `jimtof2026x-v1` の数字を `v2`、`v3`…と上げてから一緒にアップロードしてください。来場者のスマホに保存された古い版が新しい版に入れ替わります。
出展社データの編集だけなら、この作業は不要です。

## うまくいかないとき

- **データが表示されない**：手順2の公開設定で、形式が［カンマ区切り形式（.csv）］になっているか、1行目の列名が変わっていないかを確認してください。スプレッドシートを読み込めない場合は、同梱の `data.csv` が自動で表示されます。
- **編集が反映されない**：5分ほど待ってから、アプリを再読み込みしてください。
